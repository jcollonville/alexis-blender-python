# Étape 02 — Bouger

## Objectif

Déplacer ton objet avec `location` : trois nombres, **x** / **y** / **z**.

## Voir

Toujours dans Blender, encore sans code. Quelques minutes.

1. Pose ton objet dans une scène simple : un sol, ou juste de l’espace autour.
2. Ajoute une **lumière**, pour bien voir quand ça bouge.
3. Bouge l’objet à la souris, juste pour sentir les trois directions :
   - **x** : gauche / droite
   - **y** : avant / arrière
   - **z** : haut / bas

Remets-le à un endroit que tu aimes. C’est ton point de départ.

## Toucher

Un fichier `bouger.py` arrivera dans ce dossier.

L’idée du script : changer un peu `location`, par exemple en **x** ou en **z**. Puis lancer le script, et regarder.

Pas besoin d’un grand saut. Un petit pas suffit pour voir que **toi**, tu commandes l’objet.

Si tu ne vois rien : vérifie le nom de l’objet (étape 1) et que la lumière éclaire bien.

## À toi de jouer

Envoie-le ailleurs. Invente une petite série de positions. Fais-le « téléporter » d’un coin à l’autre.

Tu choisis où il va. Il n’y a pas de bonne place.

## Astuce

Change **un seul** nombre à la fois (juste x, ou juste z). Tu vois tout de suite ce qui a bougé.
